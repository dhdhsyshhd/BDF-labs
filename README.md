## Lab Summaries

### [Lab 1: Node.js and Express Server](./lab-01/README.md)
Demonstrates creating a foundational web server using Node.js and Express.js, implementing GET routes (`/`, `/about`, `/time`), and handling unknown routes with appropriate HTTP 404 status codes.

* **Technologies Used:** Node.js, Express.js, JavaScript
* **Documentation:** [View Lab 1 README](./lab-01/README.md)

---

### [Lab 2: SQLite Database and CRUD Operations](./lab-02/README.md)
Connects an Express.js server with an SQLite database (`bookStore.db`) and implements CRUD operations to create, retrieve, update, and delete book records.

* **Technologies Used:** Node.js, Express.js, SQLite, sqlite3, sqlite, JavaScript
* **Documentation:** [View Lab 2 README](./lab-02/README.md)

---

### [Lab 3: REST API, Query Parameters, Validation, and Debugging](./lab-03/README.md)
Implements an advanced RESTful Books API with query parameter filtering (`search_q`, `order_by`, `order`, `min_price`, `max_price`, `limit`, `offset`), robust request validation (`400 Bad Request`), standard status codes, systematic debugging fixes (`EADDRINUSE`, imports, schema, `async/await`), and an interactive web dashboard.

* **Technologies Used:** Node.js, Express.js, SQLite, sqlite3, sqlite, cors, Postman, JavaScript
* **Documentation:** [View Lab 3 README](./lab-03/README.md)
