## Lab Summaries

### [Lab 1: Node.js and Express Server](./lab-01/README.md)

This lab demonstrates creating a web server using Node.js and Express.js, implementing GET routes (`/`, `/about`, `/time`), and handling unknown routes with appropriate HTTP 404 status codes.

- **Technologies Used:** Node.js, Express.js, JavaScript
- **Lab Documentation:** [View Lab 1 README](./lab-01/README.md)

### [Lab 2: SQLite Database and CRUD Operations](./lab-02/README.md)

This lab demonstrates connecting an Express.js server with an SQLite database (`bookStore.db`) and implementing CRUD operations to create, retrieve, update, and delete book records.

- **Technologies Used:** Node.js, Express.js, SQLite, sqlite3, sqlite, Nodemon, JavaScript
- **Lab Documentation:** [View Lab 2 README](./lab-02/README.md)
